# Football Analyzer Pro 2.0

هذه نسخة متقدمة من التطبيق السابق.

## الجديد

### البيانات
- Fixtures يومية.
- توقعات المزود عندما تتوفر.
- Pre-match odds عندما تتوفر.
- إحصائيات المباراة.
- الإصابات.
- التشكيلات.
- xG فقط عندما يرسله مصدر البيانات؛ لا يتم اختراع قيمة ناقصة.
- Cache لتقليل استهلاك الحصة.

API-Football يعلن دعماً للمباريات، التشكيلات، الإحصائيات، الإصابات، الأودز والتوقعات، مع اختلاف التغطية بحسب المسابقة والموسم. يجب على التطبيق فحص توفر البيانات وعدم افتراض أنها موجودة لكل مباراة.

### محرك الاحتمالات
النسخة 2 تدمج:
1. توقع المزود.
2. الاحتمالات المستخرجة من الأودز عند توفرها.
3. إشارة الفورم عندما تتوفر البيانات.
4. نموذج Poisson للأهداف.
5. درجة اكتمال البيانات.
6. Confidence منفصلة عن Probability.

### الأسواق
- 1X2
- Double Chance
- Over/Under 0.5 و1.5 و2.5 و3.5
- BTTS
- Expected Goals

### السجل والاختبار
بعد انتهاء المباراة يسجل التطبيق:
- النتيجة الفعلية.
- الاحتمالات التي كانت موجودة قبل النتيجة.
- Brier Score.
- معدل إصابة التوقعات عالية الاحتمال.

Brier Score وقياس Reliability/Calibration أدوات مناسبة لتقييم جودة الاحتمالات بدلاً من الاكتفاء بعدد التوقعات الصحيحة.

## التشغيل

Node.js 18+:

```bash
npm install
```

انسخ `.env.example` إلى `.env` ثم ضع:

```env
API_FOOTBALL_KEY=YOUR_KEY
```

ثم:

```bash
npm start
```

افتح:

```text
http://localhost:3000
```

## الحصة

النسخة لا ترسل كل أنواع الطلبات لكل مباراة. هناك حدود في `.env`:
- MAX_ENRICH
- MAX_ODDS
- MAX_DETAILS

هذا مهم لأن عدد الطلبات قد يصبح كبيراً مع مباريات العالم كلها. ارفعها فقط إذا كانت خطتك تسمح.

## التحديث التلقائي

يتم تشغيل Cron داخل الخادم:
- تحديث يومي للمباريات.
- تسوية النتائج كل 30 دقيقة.

لكي يعمل 24/7 يجب استضافة Node.js على خادم مستمر التشغيل. تشغيله على الهاتف وحده لا يضمن Cron في الخلفية.

## التطوير التالي المقترح

للوصول إلى نسخة إنتاجية أقوى:
- قاعدة بيانات PostgreSQL/SQLite بدلاً من JSON.
- نظام Users.
- صفحة مباراة تفصيلية.
- Elo زمني لكل فريق.
- Dixon-Coles/Bivariate Poisson.
- نموذج ML مدرب على مواسم سابقة.
- Calibration تلقائي.
- Walk-forward backtesting.
- مقارنة Closing Odds.
- أسواق الركنيات والبطاقات والتسديدات عندما تتوفر بيانات موثوقة لها.
- تنبيهات Telegram/Push.
- لوحة إدارة للحصص والأخطاء.
- مراقبة جودة البيانات لكل بطولة.

لا ينبغي تسمية أي مخرج "مضموناً": كرة القدم احتمالية، وحتى النموذج الجيد يمكن أن يخطئ.
